# 中國區版本

此分支以 LeapMotor Mate 4.15.3 的本地記錄與網頁介面為基礎，使用 `ha-leapmotor-cn` 的 Android 認證及中國區協定，並參照 `leapmotor-app2api` 的 B01 控制請求與回執格式。第一個驗收目標為 **B01 2025、全權限共享帳號**。

## 啟動與登入

需要 Docker Engine 與 Docker Compose v2。在本分支目錄執行：

```sh
cd ~/Develop/leapmotor-mate-cn
docker compose up -d --build
```

開啟 `http://localhost:4000`（遠端伺服器使用其 IP）。在官方零跑 App 接受共享後，以中國大陸手機號碼收取短信驗證碼登入。每台車都要填寫版本對應的**電池可用容量**，不會從 B01 名稱推定容量。操作 PIN 選填；未設定時可以讀車況，但無法控車。PIN 是車輛操作密碼，與短信驗證碼不同。

預設繁體中文、人民幣（CNY）、中國標準時間（Asia/Shanghai）；可選香港或台北時區。沒有歐洲版帳號密碼或憑證上傳步驟。`MATE_MARKET=CN` 是預設值；保留的 `EU` 選項供上游回歸測試使用。

必須從本分支原始碼建置。上游的 Docker／桌面版發行包不包含此轉接器；本分支也不提示安裝上游國際版更新。更新原始碼後重新執行 `docker compose up -d --build`。

## 支援範圍

「已實作」代表程式、請求格式與離線測試已完成；**本次沒有用真實帳號登入，也未執行 B01 真車控車驗收**。配備、`rightList` 與 `moduleRights` 三項都會限制共享帳號能使用的控制。全權限共享不會使車輛增加未宣告的配備。

| 功能 | 本分支狀態 |
|---|---|
| 手機短信登入、帳號 token 與 gateway token 續期 | 已實作；跨程序共用加密登入資料 |
| 自有／共享車輛、每 VIN 區域路由、多車設定 | 已實作；以雲端清單與路由為準 |
| 被動車況、電量、里程、胎壓、車門、空調、座椅 | 已實作；缺失讀數保留未知，不補零 |
| GPS 與地圖位置 | 已實作；共享帳號需位置權限；GCJ-02 轉為 WGS-84 |
| 本地行程、充電、費用、電池估算、MQTT Discovery | 沿用記錄功能，接入中國區車況與權限 |
| 官方累計里程、每日行駛能耗、週能耗／排名 | 已實作；官方資料與本地記錄分開，逐日資料有快取與請求上限 |
| 雲端車輛圖片 | 已實作；圖片下載不附帶帳號憑證 |

| 空調完整七欄請求、快冷／快熱／換氣／除霜 | 已實作控制轉接；真車結果待驗收 |
| 前排座椅加熱／通風、方向盤／後視鏡加熱 | 已實作控制轉接；依配備與權限顯示 |
| 車窗 | 支援關閉／微開／半開／全開（0／2／5／10）；未確認四角狀態順序，僅顯示整體開啟狀態 |
| 充電上限、每週充電計畫、健康充電 | 已實作；充電計畫保留未修改欄位，等待車端回執 |
| 原生空調排程、prepare-car、導航下發 | 尚未支援；入口說明狀態，寫入 API 在連線前拒絕 |

| 官方逐筆行程／充電歷史匯入 | 尚未支援；不能用每日能耗假造逐筆行程 |
| 中國區原廠保養週期 | 尚未收錄；不套用國際版保養手冊 |

### 充電與回執的語義

中國區信號 `1149`：1 為正在充電、2 為已停止且插槍、3 為故障、4 為等待預約、6 為暫停；0／5 為未插槍，其他值為未知。行駛中的回充不會建立充電記錄，單純插槍不會視為充電完成。既有充電在 6 暫停時保持同一筆記錄，2 停止時結束。

車況新鮮度採用車端 `sts`／信號 1；伺服器 `collectTime` 只作診斷，不能把同一幀變成新資料。胎壓 kPa 轉為 bar，保留電池電流充電負值／放電正值。後排座椅信號不會套進國際版車窗解析。

控制先驗證操作 PIN，再送出一次請求。雲端標量 `msgID` 只代表受理，畫面不會直接宣稱成功；可觀察的控制再以新車況確認。充電計畫查詢收到正確的標量成功回覆後才記為已確認。逾時不會自動重送控制。

## 地圖與座標

地圖採用 `ha-leapmotor-cn` 卡片相同的高德路網與衛星瓦片，支援自動、路網、衛星、深色四種底圖；底圖偏好會保存在瀏覽器。總覽、行程、事件、月報、地圖頁與充電地點選點共用同一套投影。

車端原始 GCJ02 在收集時轉為 WGS84。資料庫、MQTT、GPS 匯出及地點設定保持 WGS84；顯示高德底圖時才轉成 GCJ02。地圖點擊／拖動產生的座標則反向轉回 WGS84，因此充電地點與半徑判定不會混用兩種座標。中國區轉換範圍以外的座標保持原值，經緯度順序為緯度在前。

多個瓦片載入失敗時，整張地圖切回 OpenStreetMap 並改用 WGS84 投影，車標與路線仍保留原始 WGS84 資料。切換底圖可重新嘗試高德；不會將 OSM 瓦片混入 GCJ02 圖格。高德縮放上限沿用參考卡片的 18 級。

## 車況輪詢

中國區行駛與快速輪詢預設為 **6 秒**；行駛間隔可在設定頁調整為 6 至 60 秒，操作後的提速亦使用 6 秒。停車與一般充電沿用原有慢速間隔（Poller 未設定時為 30 秒）。更新首次啟動會把原先儲存的 10 秒行駛間隔轉為 6 秒，其他自訂值保留；之後手動調整不會再次被覆寫。

停車結束行程的確認依輪詢間隔調整：6 秒間隔需要連續 10 次 P 檔讀數，保持約一分鐘的確認窗口；READY 仍開啟時保持同一行程。

## 車輛外觀圖片

圖片沿用 `ha-leapmotor-cn` 的取得方式：按 VIN 呼叫 `/carownerservice/v3/api/carpicture/key`，優先使用 `shareBindUrl` 的整車圖片直鏈，兼容 `url`／`imageUrl`／`picUrl`／`carPic`，HTTP 地址提升為 HTTPS。由伺服器下載並提供 PNG，CDN 請求不附帶帳號憑證，簽名直鏈不傳給瀏覽器。

每帳號、每 VIN 分別在記憶體快取；圖片地址六小時更新一次，相同地址不重複下載。地址或下載失敗保留舊圖，五分鐘後重新取得地址；`/api/car-picture?refresh=1` 可立即刷新。登出及重設清除快取，重新啟動後按需載入。中國區顯示官方整車外觀圖。

## 登入資料與備份

`./data` 保存 SQLite 資料庫、加密用的 `secret.key` 與登入資料。帳號／gateway token、簽名材料及裝置 ID 存在加密 blob，短信驗證碼不保存；每車 PIN 使用既有的加密設定機制。備份時請保留**整個 data 目錄**，只備份資料庫可能無法還原登入與 PIN。

帳號 Token 在到期前三十分鐘主動免短信續期；到期時間未知時也會嘗試續期。車端 Token 在到期前兩分鐘使用車端 refreshToken 續期；若遭認證拒絕，再用帳號續期及交換流程恢復。帳號續期暫時失敗仍可使用有效的車端 Token，沒有短信自動重登。

帳號續期失敗後從五分鐘起指數退避，最長一小時；成功後至少十五分鐘不重複續期。退避狀態與 Token 一起加密保存並由 Web／Poller 共用，重新啟動不會清掉節流。車端刷新失敗仍保留已成功更新的帳號 Token。錯誤 1023 會啟動持久化十分鐘全域冷卻，冷卻內不發出新請求；短信另有六十秒伺服器限制。兩層登入資料無法自動恢復時需手動短信登入，控車請求不會自動重送。

登出刪除中國區登入、未完成登入與帳號權限快取，保留按 VIN 儲存的本地歷史。此服務含車輛控制能力，請在「設定」啟用存取密碼，並放在你信任的網路。

## 開發驗證

需要 Python 3.12、虛擬環境及 Chromium。下列測試使用合成資料，測試框架阻擋非本機網路。

```sh
python3.12 -m venv .venv
. .venv/bin/activate
python -m pip install -r poller/requirements.txt -r web/requirements.txt pytest pytest-xdist httpx playwright
python -m playwright install chromium
python -m pytest -q tests/test_cn_adapter.py tests/test_cn_token_refresh.py tests/test_cn_car_picture.py tests/test_cn_maps.py
python -m pytest -q -n 4 --dist worksteal
```

核心覆蓋：短信設定與重啟、跨程序單次續期、帳號主動續期與持久退避、續期失敗時保留有效車端登入、實送標頭 HMAC、路由限制、PIN 先行、B01 標量回執、共享權限與帳號隔離、充電狀態、未知值、車窗／後排座椅衝突、位置權限、每日快取及 web／poller 相同入庫值。手機版另以合成 B01 帳號驗證登入與設定流程。
